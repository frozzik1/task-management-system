# Task Management System

A backend task and project management system, built step by step while learning
Java from scratch. The goal is to evolve a simple console application into a
production-style REST service.

## Tech Stack

- Java 25 (LTS)
- Maven
- Planned: PostgreSQL, Hibernate/JPA, Spring Boot, Spring Security (JWT),
  JUnit 5, Mockito, Docker

## Roadmap

- [ ] Java basics: types, memory model, methods, control flow
- [ ] Console menu for managing tasks
- [ ] OOP: domain model, SOLID, clean architecture
- [ ] Collections, exception handling, file I/O
- [ ] Unit testing with JUnit 5
- [ ] PostgreSQL, JDBC, Hibernate/JPA
- [ ] Spring Boot REST API
- [ ] Authentication and authorization (Spring Security, JWT)
- [ ] Dockerization and CI

## Status

Work in progress. The commit history shows the evolution of the project.
